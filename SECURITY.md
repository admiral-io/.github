# Security Policy

We deeply appreciate any effort to discover and disclose security vulnerabilities responsibly.

## Reporting a Vulnerability

If you would like to report a vulnerability or have security concerns, please email [security@admiral.io](mailto:security@admiral.io). We will acknowledge your report and follow up with next steps.

Please **do not** file a public GitHub issue for security vulnerabilities.

To help us respond quickly, please include as much of the following as you can:

- Steps to reproduce or proof-of-concept
- Affected project and version
- Any relevant tools, including versions used
- Tool output or error messages
