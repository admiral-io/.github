# .github

Default community files for every public repository in the Admiral
organization, and the organization profile.

- [profile/README.md](profile/README.md): the page shown at [github.com/admiral-io](https://github.com/admiral-io)
- [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md): community behavior expectations, based on Contributor Covenant 3.0
- [CONTRIBUTING.md](CONTRIBUTING.md): where an issue goes, and how to open a pull request
- [SECURITY.md](SECURITY.md): how to report a security vulnerability
- [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE): the default bug and feature forms
- [actions/setup-admiral](actions/setup-admiral/action.yaml): installs the `admiral` CLI in a GitHub Actions workflow

A bug in one repository's code is filed in that repository. Everything else,
including questions, goes to
[admiral-community](https://github.com/admiral-io/admiral-community). See
[CONTRIBUTING.md](CONTRIBUTING.md).
