## Welcome to Admiral!

![Admiral](https://raw.githubusercontent.com/admiral-io/.github/master/profile/admiral-logo.svg)

Admiral is a control plane for coordinating infrastructure and application delivery across environments. It sits between your IaC and your deployment tooling, maintains the dependency graph across both, and gives you an application-centric model that reduces environment duplication.

### What we build

- A control-plane server and distributed execution components
- A CLI and GitHub Action for CI/CD workflows
- A Terraform provider for managing Admiral as code
- A fully documented OpenAPI spec
